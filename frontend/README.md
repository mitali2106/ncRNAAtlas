# ncRNAAtlas frontend

React + Vite single-page app for ncRNAAtlas. See the [project README](../README.md) for setup.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to http://127.0.0.1:5000 (override with VITE_API_PROXY)
npm test         # Vitest + React Testing Library
npm run build    # static build in dist/
```
